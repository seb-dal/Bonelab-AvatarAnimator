# Bonelab-AvatarAnimator

Bonelab mod to allow the usage of a more complexe Unity Animator Controller inside the Game using player inputs.
This mod only change visual element of the avatar and play audios.

# Documentations
https://github.com/seb-dal/Bonelab-AvatarAnimator/wiki

# Installation

Build with MelonLoader 0.7.1 and BoneLib 3.2.2. 

- PC / Quest Link: copy `Mods/AvatarAnimator.dll` into BONELAB's `Mods` folder.
- Quest standalone: Copy the same DLL into `/sdcard/MelonLoader/com.StressLevelZero.BONELAB/Mods/`.

Fusion is optional
